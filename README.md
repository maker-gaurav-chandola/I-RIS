# I-RIS

## Interview Response Intelligence System

**Practice Interviews. Get Smarter Feedback. Improve Every Time.**

I-RIS is an AI-powered mock interview platform for realistic technical interview practice. It conducts adaptive, conversational interviews with contextual follow-up questions, then analyzes responses and provides structured feedback to help candidates improve with each practice session.

**Primary target users:** Students and freshers preparing for technical job interviews, especially in the Indian context, with support for English and natural conversational Hinglish.

**Core purpose:** Enable candidates to practice realistic interviews without requiring a human interviewer, understand their strengths and weaknesses, and improve over time through the cycle of practice, feedback, and repeated practice.
